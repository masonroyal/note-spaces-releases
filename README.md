# Note Spaces (releases)

Arc-browser-style spaces for your notes in Obsidian: per-space pinned and temporary tabs, split views, and idle auto-archive with per-space history.

This repo holds the release builds. The source is developed in a separate private repo, so issues here may not get a reply.

## Install with BRAT

1. In Obsidian, install and enable **BRAT** from Community plugins.
2. In BRAT's settings, choose **Add beta plugin**.
3. Enter `masonroyal/note-spaces-releases` and pick the latest version.
4. Enable **Note Spaces** under Community plugins.

No GitHub token is needed. BRAT can keep the plugin up to date from here.

## Install by hand

Download `main.js`, `manifest.json` and `styles.css` from the latest release into `<your vault>/.obsidian/plugins/note-spaces/`, then enable the plugin.

This is beta software. Back up your vault before trying it.
